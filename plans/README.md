- **`157369a`** — committed a separate, already-finished but never-committed feature set (mobile menu accessibility, context-aware WhatsApp button, contact form overhaul with honeypot + auto-reply, `globals.css` additions the pages from `49f5bbd` depend on for styling, security headers, `viewport` export). This was blocking: the pages merged in `49f5bbd` reference `sp-*` CSS classes that only existed in this uncommitted diff — without it those 63 pages rendered unstyled in production.

All 90 worktrees and their `worktree-agent-*` branches were removed after merging (`git worktree remove` + `git branch -D`) — the specific worktree IDs referenced in the "DONE" statuses above no longer exist; the commit hash is now the source of truth.

- ~~**`middleware.ts` was missing**~~ — correction: it wasn't missing, it was **renamed to `proxy.ts`** in the same commit (`5073a62`) that removed it, as part of migrating to Next.js 16 (which replaced `middleware.ts` with `proxy.ts`; having both files present is a hard build error). `proxy.ts` already contains the `Accept-Language` → `/en/` redirect plus the `/admin` auth guard. On 2026-08-13 a `middleware.ts` was mistakenly re-added (duplicating `proxy.ts`'s redirect logic) without checking for `proxy.ts` first, which broke the Vercel build (`Both middleware file "./middleware.ts" and proxy file "./proxy.ts" are detected`) and blocked deployment of the CYPE-brand and README changes. Reverted same day — see commit history for `middleware.ts`.
